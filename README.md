# Sacramento Kings Data Science Assessment

**Candidate Submission** - ghadfield32

This repository contains my analysis and recommendations for international basketball players that the Sacramento Kings should scout, based on the provided NBA and European league data.

Work in whatever language you are most comfortable in.

## Context
The analytics staff of the Sacramento Kings needs to provide some recommendations for players currently playing outside of the NBA for the GM to target. Your job is to create a report highlighting a few international players that we should make sure our scouts have eyes on this year.

**Your goal**: use the JSON files in this repository to create tables within your assigned schema (more detail on this below), and then perform an analysis to output a report. There are a few things we are looking for here:
- Data ingestion and cleaning
- Insight into how you do Exploratory Data Analysis (EDA)
- Your communication and reporting skills

## Data
In the `/api_data_files` folder of this repository, there are 3 JSON files with mock data on players who have played both in the NBA and one of the 4 main Euroepan leagues (EuroLeague, EuroCup, Spain - ACB and Italy - Liga A). This data has been anonymized and randomized to focus more on your process of data science than any specific results. Assume the NBA and European data come from two different vendors and need some processing to be usable together. For reference, the season variable indicates the year the season ended, i.e. 2019 represents 2018-19.
